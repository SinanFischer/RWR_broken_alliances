# Umsetzungswissen

Dieser Ordner ist fuer operatives Wissen aus realen Implementierungen.

## Ziel

- Entscheidungen nachvollziehbar festhalten
- technische Stolpersteine dokumentieren
- spaetere Erweiterungen schneller und sicherer machen

## Was hier reingehoert

- konkrete "Ist-Stand"-Notizen zu aktiven Systemen
- bewusst deaktivierte Features mit Grund
- Schnittstellen und Schalter (Flags, Registry-Parameter)
- bekannte Grenzen der Engine/API

## Was hier nicht reingehoert

- reine Feature-Ideen ohne Umsetzungsbezug (dafuer `docs/konzepte`)
- allgemeine Grundlagen ohne Projektbezug

## Benennung

Empfehlung: pro Themenblock eine Datei, z. B.:

- `WISSEN_STAND_SYSTEME.md`
- `WISSEN_SPAWN_CAPACITY_BETRIEB.md`
- `WISSEN_COMMAND_REGISTRY.md`
